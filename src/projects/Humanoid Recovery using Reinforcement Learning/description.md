Developed a robust control policy for a humanoid robot capable of recovering from falls and transitioning into a stable walking gait. This project was built for the **Reinforcement Learning** class at Tufts University using **Unity ML-Agents** and **Proximal Policy Optimization (PPO)**.

## Key Features

- **Curriculum Learning**: Multi-stage training to progressively develop complex motor skills.
- **Modular Task Decomposition**: Discrete separation of task complexity for easier learning.
- **ML-Agents**: Realistic rigid-body dynamics in Unity + efficient RL training in pytorch
